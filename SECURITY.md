# Security Policy

## Reporting a Vulnerability
If you find a security issue, please do not open a public issue immediately.

Contact the maintainer privately and include:
- Vulnerability description
- Reproduction steps
- Impact assessment
- Suggested remediation (if available)

## Supported Versions
The latest `main` branch is currently supported.

## Secrets Handling
Never commit real tokens, keys, or `.env` files. Use `.env.example` for configuration templates.
